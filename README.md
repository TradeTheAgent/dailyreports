# dailyreports

Public-facing styled daily HTML reports for the TradeTheAgent (TTA) experiment. Moved here from [wiredout46/tta-reports](https://github.com/wiredout46/tta-reports), which now only carries archival history prior to the move.

## Structure

- `reports/YYYY-MM/market-report-YYYY-MM-DD.html` — one folder per month.
- `index.html` — landing page listing all reports by month.

## Note

This repo does not run anything and has no code. It's a plain document store, archived and retrieved on request.
